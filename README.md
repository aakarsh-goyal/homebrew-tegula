# homebrew-tegula

Homebrew tap for [Tegula](https://github.com/aakarsh-goyal/tegula), automatic window tiling for macOS.

```sh
brew install --cask aakarsh-goyal/tegula/tegula
```

Apple silicon, macOS 15+. The app is ad-hoc signed (not notarized); the cask clears the download
quarantine flag. Grant Accessibility access on first launch.
